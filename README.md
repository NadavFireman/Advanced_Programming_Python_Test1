# Advanced Programming: Exam 1 Solution - Data Analysis and Problem Solving

This repository contains the solution for a mock exam in the Advanced Programming course (Shenkar College, IE&M).

The project assesses the ability to efficiently apply core Python and Pandas skills for data analysis and problem-solving under strict time constraints.

## Key Skills Demonstrated

* **Time-Constrained Problem Solving:** Demonstrating the ability to implement clean, optimized code solutions within a limited time frame.
* **Pandas Mastery:** Advanced application of DataFrames for conditional filtering, grouping, aggregation, and statistical summarization on the `StudentsPerformance.csv` dataset.
* **Algorithmic Application:** Implementing fundamental algorithmic concepts (e.g., distance calculation, search logic) alongside high-level library functions.
* **Data Preprocessing:** Performing essential steps like data imputation, normalization, and one-hot encoding as required by the exam.

## Repository Content

* **`Advanced_Programming_Test1.ipynb`**: Full Python solution notebook with code and analysis results.
* **`StudentsPerformance.csv`**: The dataset used in the examination.
* **`docs/Test_Instructions_1.pdf`**: Original examination instructions.
